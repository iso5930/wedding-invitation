## 예정: URL 공유 썸네일 및 미리보기

목적: 카카오톡 등에 청첩장 URL을 전달했을 때 대표 이미지·제목·설명이 의도한 내용으로 표시되도록 한다.

### 1. 공유 콘텐츠 준비

- [ ] 공유 제목 확정: 실제 신랑·신부 이름과 초대 문구 반영
- [ ] 공유 설명 확정: 결혼 날짜, 예식장 라비니움 등 확정 정보 반영
- [ ] 청첩장 분위기에 맞는 공유 전용 썸네일 이미지 제작
- [ ] 작은 미리보기에서도 이름·날짜 등 핵심 내용이 읽히는지 확인
- [ ] 이미지를 `public/images/`에 저장하고 실제 파일 크기·비율 확인

공유 이미지는 웹페이지 첫 화면과 별도로 제작할 수 있다. 현재 프로젝트에 OG 태그나 공유용 이미지를 추가하는 작업은 아직 진행하지 않았다.

### 2. 웹페이지 설정

- [ ] 루트 `index.html`의 `<head>`에 `og:title`, `og:description`, `og:image`, `og:url`, `og:type`, `og:site_name` 설정
- [ ] `og:image:alt`와 이미지의 실제 너비·높이 메타정보 추가
- [ ] React 실행 후가 아닌, 처음 내려오는 HTML에 OG 태그가 포함되는지 확인
- [ ] `og:url`에 청첩장 대표 주소 사용: https://iso5930.github.io/wedding-invitation/
- [ ] `og:image`에 GitHub Pages의 저장소 하위 경로를 포함한 전체 HTTPS 이미지 주소 사용
- [ ] 이미지 교체 시 파일명을 버전으로 구분하여 관리

### 3. 배포 및 실제 공유 검증

- [ ] 빌드와 GitHub Pages 배포
- [ ] 로그인 없이 대표 이미지 주소가 열리고 HTML에서 OG 태그가 확인되는지 검사
- [ ] 카카오디벨로퍼스 URL 메타정보 도구로 제목·설명·이미지 확인
- [ ] 이전 이미지나 문구가 남아 있으면 해당 URL의 OG 캐시 초기화
- [ ] 카카오톡에 URL을 새로 공유해 실제 썸네일, 문구 잘림, 이미지 잘림 확인
- [ ] 미리보기 카드를 눌렀을 때 청첩장 대표 주소로 이동하는지 확인

완료 기준: 새로 공유한 청첩장 URL에서 확정된 썸네일·제목·설명이 표시되고, 클릭 시 정상적으로 청첩장이 열린다.
